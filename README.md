# 📚 Projeto Integrador II - UNIVESP

Repositório oficial do Projeto Integrador II da **Universidade Virtual do Estado de São Paulo (UNIVESP)**. O sistema consiste em uma aplicação web voltada para a gestão de equipamentos, manutenções e controle de usuários, dividida entre uma API de back-end e uma interface de front-end.

---

## 📂 Estrutura do Repositório

O projeto está organizado em formato monorepo, contendo as seguintes pastas principais:

- **`/back`** : Contém o código-fonte da API, regras de negócio, serviços, controladores e integração com a base de dados.
- **`/front`** : Contém o código-fonte da interface de utilizador (SPA), construída com React, Vite e React Query.

---

## 🛠️ Tecnologias Utilizadas

### **Back-End (`/back`)**

- Node.js & Fastify / Express (conforme arquitetura adotada)
- Prisma ORM / PostgreSQL ou SQLite
- JWT para autenticação e bcrypt para segurança de senhas

### **Front-End (`/front`)**

- React 18 & Vite
- TanStack React Query (gerenciamento de estado e cache)
- React Router DOM
- CSS Responsivo e Modularizado
